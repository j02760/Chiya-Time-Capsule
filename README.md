# 我的個人博客

這裡是我的個人站點，主要記錄生活、技術筆記、閱讀與感想。

> 這個博客以 Astro 7.0 + 自定義設定為基礎，內容以個人使用為主，簡潔、實用、長期維護。

## 關於本站

- 記錄生活與思考
- 分享技術與實作心得
- 保存作品、筆記與靈感
- 以簡潔的方式呈現內容，不做過多功能堆疊


ㄋ
## 項目結構

- `src/content/blog/`：文章內容
- `src/pages/`：頁面與路由
- `src/components/`：前端組件
- `config/site.yaml`：站點設定
- `public/`：靜態資源
